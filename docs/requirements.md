# CrossPost 需求文档

## 产品目标

帮助创作者在微信公众号、知乎、B站、小红书、抖音五个平台同步发布内容，自动适配各平台格式与风格。

## 核心功能

1. **内容输入**：Markdown 编辑器，支持标题、正文、标签、媒体素材
2. **AI 文案生成**：上传图片/视频或粘贴长文 → 多阶段 AI 生成各平台适配文案
3. **格式适配**：长文流(Markdown→HTML) + 短文流(Markdown→纯文本)双管道
4. **平台预览**：5 平台实时预览，iframe 沙箱隔离样式
5. **一键发布**：模拟发布，per-platform 状态独立

## 用户故事

- 作为创作者，我粘贴一篇技术长文，AI 自动帮我提炼小红书种草文案和抖音视频脚本
- 作为摄影博主，我上传一组照片，AI 识别内容后生成各平台适配的描述文案
- 作为运营，我勾选 5 个平台，一键预览各平台最终效果，确认后模拟发布
